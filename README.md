# Stitchfits Digitizing Lab

Digitizing Lab is an optional Windows add-on for turning SVGs and raster artwork into editable embroidery. Review colors, preview stitches, then open the design in Stitchfits to refine it.

[**Install Digitizing Lab v0.2.24 for Windows**](https://github.com/RoguePixelLabs/stitchfits-digitizing-lab/releases/download/v0.2.24/StitchFits-Digitizing-Lab-Setup-v0.2.24-Windows-x64.exe) · [Portable ZIP](https://github.com/RoguePixelLabs/stitchfits-digitizing-lab/releases/download/v0.2.24/StitchFits-Digitizing-Lab-Windows-x64.zip) · [Release notes and source](https://github.com/RoguePixelLabs/stitchfits-digitizing-lab/releases/tag/v0.2.24)

1. Run the Windows Setup EXE. It installs for your Windows account.
2. Open **StitchFits Digitizing Lab** from the Start menu or use **Design → Digitizing Lab** in StitchFits.
3. In the Lab, open **Help → User Guide** for a walkthrough.

Use **Help → Check for Updates** in StitchFits to check for new Lab releases. Run the latest Setup EXE to update your installed copy. The portable ZIP can run from an extracted folder.
